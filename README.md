# FDC - Federytion Du Commerce (dossier EryAddon)

Add-on pour **World of Warcraft: Forever** (client en français) : nouvelle fenêtre d'hôtel des ventes (Acheter,
Opportunités, Vendre, Mes enchères, Mes ventes, Métiers), icônes dans les sacs, carte des livres, etc.
Tape `/fdc` en jeu pour activer ou désactiver chaque fonction.

Conseillé : **TradeSkillMaster** (TSM) et son application, pour les prix du marché et les ventes par jour.
Auctionator n'est plus nécessaire.

## Installer (la première fois)

1. Sur cette page, clique sur le bouton vert **Code**, puis **Download ZIP**.
2. Ouvre le fichier zip : il contient un dossier `EryAddon-main`.
3. Copie ce dossier dans `World of Warcraft\_forever_\Interface\AddOns\`
   et renomme-le **`EryAddon`** (exactement ce nom, sinon le jeu ne le charge pas).
4. Lance le jeu.

## Mettre à jour

Dans le dossier `AddOns\EryAddon`, double-clique sur **`Mettre a jour EryAddon.bat`**.
Il dit si une nouvelle version a été installée. Ensuite, en jeu : `/reload`
(si une nouveauté n'apparaît pas, relance le jeu).

La 1re fois, Windows peut demander une confirmation (« Windows a protégé votre ordinateur ») :
clique sur **Informations complémentaires**, puis **Exécuter quand même**.

Tes réglages ne sont jamais touchés par la mise à jour (ils sont dans le dossier `WTF`).
